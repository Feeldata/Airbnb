# Airbnb Paris Data Analysis – Work Log

## Data Sources

- **Paris Neighborhoods (Arrondissements):**  
  [data.gouv.fr – Arrondissements](https://www.data.gouv.fr/en/datasets/arrondissements-1/)

- **Airbnb Listings in Paris:**  
  [Kaggle – Airbnb Paris Listings](https://www.kaggle.com/datasets/abaghyangor/airbnb-paris)

## Workflow

1. **Data Acquisition**
   - Downloaded the CSV file for Paris neighborhoods.
   - Downloaded the latest Airbnb listings dataset for Paris.

2. **Data Cleaning**
   - Cleaned the arrondissement data in Excel.
   - Cleaned the Airbnb dataset for consistency and accuracy.

3. **Data Integration**
   - Moved the cleaned datasets into Tableau for analysis.

4. **Challenges & Solutions**
   - **Challenge:** Struggled with the CSV neighborhood file (formatting and compatibility issues).
   - **Solution:** Downloaded the direct GeoJSON file and cleaned it. Matched the neighborhood names in the listings data to the official arrondissement names.

5. **Analysis Planning**
   - Established key stakeholder questions (for an investor interested in Airbnb rentals in Paris):
     - What is the average price per neighborhood?
     - How much competition is there (verified vs. unverified hosts)?
     - What is the average price per bedroom?
     - Is there a correlation between verified superhosts, neighborhood, and average price?

6. **Visualization**
   - Visualized findings in Tableau.
   - Developed a narrative to communicate insights using Tableau dashboards.

## Notes

- All data cleaning and transformation steps are documented for reproducibility.
- The project is designed to answer initial stakeholder questions and provide actionable insights.
